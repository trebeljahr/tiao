# Selected Tiao store artwork

Approved 23 October 2026: framed glyph left of the wordmark, existing board palette and a five-hop route preview. These are promotional illustrations, not gameplay screenshots. `position.json` records the setup and route; a sixth hop remains available by design.

Run `node scripts/store-art.mjs` from the repository root to render the nine SVG masters, transparent library logo and existing app icon into `build/store-media/`. The homepage uses this position translated by (+5, −4) to centre it on its full board.

Approval history, rejected iterations, recipes and console proofs are in the local project vault under `projects/tiao/assets/design-history/2026-10-23/library-art-layout-review/revisions/v11/`.
