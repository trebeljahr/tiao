# Gameplay screenshot sources

`long-match.json` and `compact-match.json` are complete matches generated by
`scripts/generate-screenshot-ai-matches.ts`. Both sides use the shipped
`findBestMove` engine with its normal Intermediate/Hard search budgets. Games
start with the empty board. Generation supplies no scripted moves, starting
pieces or random seed to the AI. Every returned decision is applied and retained, including
the final winning turn. Search depth, node count, elapsed time and board checksum
are recorded per decision; the source engine checksum identifies the implementation.

The third source is the existing complete trailer match in
`../store-trailer/ai-match.json`. Exporting screenshots replays these records
through the actual local-game UI and checks the rendered board after every move.
Replay and theme screenshots render prefixes of the same self-play records.
Game-history and tournament fixture boards also come from these records. Names,
avatars and tournament scheduling are sample UI data.

`store-ai-scenes.mjs` validates the logs before choosing any frame. Screenshot
provenance records the source ledger checksum, turn and board checksum. The store
selection embeds that provenance and rejects board images with no AI source.
Tutorial boards remain authored teaching examples, separate from gameplay.
